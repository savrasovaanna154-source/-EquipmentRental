# Прокат оборудования (Equipment Rental)
Веб-приложение для бронирования и учета спортивного, туристического и строительного инвентаря.
## Функционал
- Каталог с фильтрами и ценами
- Регистрация и авторизация (Клиент, Менеджер, Администратор)
- Бронирование на выбранные даты (с проверкой пересечений)
- Учет склада и штрафов
- Панель администратора и статистика
## Стек технологий
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express (в разработке)
- **База данных:** SQLite (в разработке)
## Статус проекта
В процессе разработки (учебная практика).
